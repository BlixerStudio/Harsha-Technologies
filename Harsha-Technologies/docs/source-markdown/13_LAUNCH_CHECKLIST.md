# 13_LAUNCH_CHECKLIST.md

# PRE-LAUNCH + POST-LAUNCH MASTER CHECKLIST

## PRIMARY GOAL

Launch cleanly, preserve authority, capture leads from day one, and avoid silent failures.

# PHASE A - PRE-LAUNCH TECH CHECK

## Domain

- domain connected correctly
- www redirect configured
- https active
- SSL valid

## Hosting

- production deployment stable
- environment variables configured
- no staging indexation leaks

## Speed

- homepage loads fast on mobile
- image compression complete
- JS bundles optimized
- fonts optimized

## Crawlability

- robots.txt correct
- sitemap.xml live
- canonical tags live
- no accidental noindex tags

## Redirects

- old URLs mapped
- 301 redirects active
- broken legacy URLs handled

# PHASE B - PRE-LAUNCH CONTENT CHECK

## Core Pages Complete

- homepage
- services hub
- contact
- kukatpally page
- hp repair page
- business amc page
- reviews

## Copy Quality

- no placeholders
- no lorem ipsum
- no grammar issues
- no duplicate blocks

## Trust Accuracy

- phone number correct
- address correct
- hours correct
- service claims true

# PHASE C - CTA CHECK

## Buttons Tested

- call buttons dial correctly
- WhatsApp opens correctly
- direction link opens map
- forms submit correctly

## Lead Flow

- thank you page works
- email notifications work
- spam filter works

# PHASE D - SEO CHECK

## Metadata

- titles unique
- meta descriptions unique
- H1 present
- OG tags present

## Schema

- LocalBusiness valid
- FAQ valid where used
- Breadcrumb valid

## Internal Links

- no dead links
- hub pages connected
- route depth logical

# PHASE E - MOBILE CHECK

Test on:

- Android small screen
- Android large screen
- iPhone width equivalent
- tablet width

## Must Pass

- sticky CTA visible
- no overflow
- forms usable
- text readable
- menu smooth

# PHASE F - GBP ALIGNMENT CHECK

- same business name
- same phone
- same address
- same service categories reflected
- website link updated in GBP

# PHASE G - ANALYTICS CHECK

- GA4 firing
- Search Console verified
- Ads tag installed
- phone click event tracked
- WhatsApp click tracked
- form submit tracked

# PHASE H - SECURITY CHECK

- forms sanitized
- captcha or anti-spam enabled
- admin secrets hidden
- backups enabled

# LAUNCH DAY ACTIONS

1. Push production
2. Smoke test core pages
3. Test CTAs
4. Submit sitemap
5. Request indexing for priority pages
6. Update GBP website if needed
7. Announce internally

# FIRST 72 HOURS

Monitor:

- form submissions
- broken links
- crawl errors
- speed regressions
- call clicks
- WhatsApp clicks

# WEEK 1 ACTIONS

- submit more pages to index
- watch search queries
- improve CTR titles
- refine CTA placement
- collect new reviews

# WEEK 2 ACTIONS

- launch more area pages
- launch more brand pages
- start ads if ready

# MONTH 1 ACTIONS

- publish blogs
- build citations
- add fresh photos to GBP
- review conversion data

# RED ALERT ISSUES

Fix immediately if found:

- phone button broken
- WhatsApp broken
- forms failing
- site slow
- sitemap missing
- noindex mistake

# SUCCESS METRICS AFTER 30 DAYS

- increase calls
- increase GBP clicks
- ranking movement
- commercial inquiries
- returning visitors

# GOLDEN RULE

A smooth launch saves months of regret.
