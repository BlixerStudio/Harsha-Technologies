# 11_BUILD_RULES.md

# MASTER BUILD RULES FOR CODEX

## PRIMARY DIRECTIVE

Build a production-grade growth website for Harsha Technologies.

Every decision must improve:

- calls
- WhatsApp leads
- commercial inquiries
- SEO authority
- mobile conversion
- long-term scalability

# NON-NEGOTIABLES

## Mobile First

Design for phone users before desktop users.

## Speed First

Fast load times over decorative complexity.

## Conversion First

Every page should help user contact business.

## Trust First

Real proof beats flashy design.

## SEO First

Pages must be crawlable, indexable, and useful.

# TECH STACK RULES

Choose modern reliable stack.

Recommended:

- Next.js
- TypeScript
- Tailwind
- Component architecture
- Static generation where useful

# FILE STRUCTURE RULES

/src
/components
/content
/public
/lib
/schema
/styles

No chaotic nesting.

# UI RULES

## Use Clean Layout

- clear spacing
- readable typography
- strong contrast
- obvious CTAs

## Avoid

- clutter
- slider spam
- intrusive popups
- noisy animation
- dark patterns

# HEADER RULES

Sticky header with:

- logo
- nav
- Call CTA
- WhatsApp CTA

# MOBILE RULES

Persistent bottom action bar:

- Call
- WhatsApp
- Directions

Large tap targets.

# PAGE BUILD RULES

Every page must contain:

- H1
- trust signals
- clear copy
- internal links
- CTA
- schema
- metadata

# COPY RULES

Write like skilled local operator.

Avoid:

- generic AI fluff
- keyword stuffing
- fake claims
- empty slogans

# SEO BUILD RULES

## Required

- unique title tags
- unique meta descriptions
- canonical tags
- breadcrumbs
- XML sitemap
- robots.txt
- structured data

## Forbidden

- duplicate route content
- doorway spam
- hidden text
- thin pages

# COMPONENT RULES

Create reusable components:

- HeroSection
- TrustBar
- CTAButtons
- ServiceGrid
- ReviewBlock
- FAQAccordion
- AreaLinks
- Footer
- StickyMobileBar

# IMAGE RULES

Use optimized images.

Compress assets.

Lazy load below fold.

Use descriptive alt text.

# FORM RULES

Minimal friction forms:

Fields:

- Name
- Phone
- Area
- Issue
- Business / Home

# CTA RULES

Primary CTA:

Call Now

Secondary CTA:

WhatsApp

Commercial CTA:

Request AMC Callback

# INTERNAL LINKING RULES

Every page links to:

- relevant service page
- relevant area page
- contact page
- one commercial page

# BRAND RULES

Use consistent brand language:

Harsha Technologies

Never alternate randomly.

# CONTENT SCALE RULES

When generating route pages:

Use templates + custom local sections.

No clone armies.

# CODE QUALITY RULES

- readable code
- modular components
- no dead code
- typed props
- clean naming
- maintainable structure

# ANALYTICS RULES

Install:

- GA4
- Search Console verification
- Ads conversion tags
- click tracking for phone + WhatsApp

# SECURITY RULES

- sanitize forms
- no exposed secrets
- env vars for keys
- spam prevention

# ACCESSIBILITY RULES

- semantic HTML
- labels for forms
- keyboard friendly
- alt text
- contrast safe

# DEPLOYMENT RULES

Production ready on:

- Vercel preferred
- CDN assets
- HTTPS only

# FORBIDDEN SHORTCUTS

Do not:

- auto-generate junk pages
- use lorem ipsum
- leave placeholder copy
- create broken links
- ship unfinished forms

# FINAL JUDGMENT TEST

Would a stressed office admin trust this site in 10 seconds?

If no, improve it.

# GOLDEN RULE

Beautiful is welcome.

Useful is mandatory.
